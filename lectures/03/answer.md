## 宿題

- 取り組んだレベル：基礎
- やったこと：エージェントがツールを使うときに、docstringがどう影響するのかを確かめるため、app/tools.pyのsearch_glossary の説明文を「用語を1つだけ入れる」から「カンマ区切りで複数まとめて入れる」に書き換えて、uv run python -m app.agent --trace "「基礎」と「発展」の違いは何ですか？" を実行しました。

- 結果：トレースログを見ると、指示どおり search_glossary({'query': '基礎, 発展'}) と2つの単語を1回にまとめて検索してくれました。ただ、そのまま「基礎, 発展」というひとまとまりの言葉として検索してしまったようで、用語集からは「見つかりませんでした」という回答になりました。

- 気づき・疑問：docstringを少し変えるだけでも、モデルがちゃんとそれを読んでツールの使い方を変えてくれたことが分かりました。ただ、モデルが指示通りにまとめて探そうとしても、ツール側でうまく見つけられないこともあるんだなということも分かりました。AIへの指示の仕方だけでなく、ツールがどう動くかも意識しないといけないのが難しいところだなと感じました。
